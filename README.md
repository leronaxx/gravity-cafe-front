Статичный сайт Gravity Café на чистых HTML, CSS и JavaScript.

## Структура
- `index.html` — главная страница.
- `menu.html` — меню и предзаказ.
- `reservation.html` — бронирование столика.
- `about.html` — информация о кафе.
- `styles.css` — общие стили.
- `scripts.js` — логика навигации, меню, корзины и бронирования.
- `ai-assistant.js` — чат-виджет ИИ-ассистента (подключён на всех страницах).
- `ai-assistant.css` — оформление чат-виджета.
- `public/` — изображения для меню и разделов.

## Как открыть
Откройте `index.html` (или любую другую страницу) в браузере напрямую из файловой системы или поднимите любой статичный сервер в корне проекта:
```bash
npx http-server .
```

## Что есть
- Навигация с мобильным меню.
- Три зоны на выбор и подробная форма бронирования.
- Предзаказ с корзиной, подсчётом времени приготовления и подтверждением.
- Тёплая цветовая палитра, сетки и карточки без сторонних библиотек.

## ИИ-ассистент «Грави»

В правом нижнем углу каждой страницы — кнопка **«Спросить ИИ»**. Ассистент
помогает выбрать блюда и напитки, рассказывает о калорийности, БЖУ и
аллергенах, сообщает адрес, часы работы и историю кафе, подсказывает, как
забронировать столик.

Что важно знать про виджет:

- он обращается к бэкенду `gravity-cafe-back` по адресу `/api/assistant/...`;
- ответ приходит потоком (Server-Sent Events) и печатается постепенно;
- виджет видит корзину гостя (`window.__gravityCart`) и учитывает её в советах;
- ответы экранируются перед вставкой в страницу (защита от XSS);
- история диалога сохраняется в `localStorage`;
- кнопки 👍/👎 отправляют оценку ответа на сервер.

### Адрес API

По умолчанию виджет сам определяет адрес бэкенда:

| Как открыт сайт | Адрес API |
|---|---|
| `file://` (двойной клик по `index.html`) | `http://localhost:3000/api` |
| статический сервер на другом порту | `http://<хост>:3000/api` |
| тот же сервер, что и API | `/api` |

Если бэкенд работает на другом адресе, укажите его до подключения виджета:

```html
<script>
  window.GRAVITY_API_BASE = "http://192.168.1.10:3000/api";
</script>
```

Перед демонстрацией запустите бэкенд:

```bash
cd ../gravity-cafe-back/server && npm start
```

Полная документация по ассистенту: `gravity-cafe-back/docs/ИИ-АССИСТЕНТ.md`.
